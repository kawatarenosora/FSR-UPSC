AMD FidelityFX FSR 3 compute shaders (ACCUMULATE / DEPTH_CLIP / LOCK / MV_GEN /
RECONSTRUCT / RCAS / SHADING_CHANGE), as distributed inside fsr-reloaded 2.1.0
(shader pack "fsr-reloaded", com.fsr2mod) which itself carries the AMD
FidelityFX SDK sources under the AMD FidelityFX license / MIT-compatible terms
noted in natives/AMD_FSR_API_LICENSE.txt of that mod. The mod's own FSR3 set is
its GLSL port of the FSR 3.1 compute subset (no FG passes shipped there; FG
runs native).

Project Zomboid local mod copies are for development study. The embedded
runtime copies live in src/fsrupsc/Fsr3Shaders.java (generated by
scripts/gen-shaders.ps1 from these files -- edit here and regenerate).

Mod-specific glue inside these files (sky/cloud/heuristic patches, dated
comments) was tuned for Minecraft; the FSR-UPSC port disables it via uniforms
rather than editing the math (see docs/PHASE2-FSR3-GLSLDESIGN.md section 1.5).
